# MercuryOps: учебный режим

- Связанный рефакторинг модели, конструктора и тестов выполняется как одно законченное изменение. Не оставлять пользователя на промежуточном некомпилируемом состоянии и не предлагать запускать тесты до завершения всех связанных правок.
- Если пользователь явно передал реализацию ассистенту, ассистент сам изменяет код и тесты, проверяет результат и делает понятный коммит.
- Для самостоятельных упражнений сначала объяснять цель и границы изменения; код, команды и тесты выполнять только после свежего разрешения пользователя.
- SKU остаётся числовым `int64`; не заменять его строкой без явного требования пользователя.
